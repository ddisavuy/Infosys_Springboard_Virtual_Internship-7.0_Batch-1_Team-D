# 📊 Supply Chain Visibility System with Optimization Analytics — Group 1

## 🚀 Project Overview

This project was completed as part of our internship with **Infosys Springboard Virtual Internship 7.0**.

**Supply Chain Visibility System with Optimization Analytics** is an interactive **Data Analytics project** designed to analyze supply chain data and provide meaningful insights into:

- Sales
- Orders
- Customers
- Products
- Delivery operations
- Geographic markets
- Costs
- Discounts
- Shipping
- Profitability

The project uses **Microsoft Power BI, Power Query, DAX, Microsoft Excel, and Microsoft Teams** to transform the **DataCoSupplyChainDataset** into meaningful insights and an easy-to-understand dashboard experience.

The project demonstrates how **Data Analytics and Business Intelligence** can be used to solve real-world supply chain problems through data-driven insights, interactive visualizations, KPI analysis, and meaningful business interpretation.

## 📊 Project Workflow

### 1. Data Collection

The **DataCoSupplyChainDataset** was used as the primary source of supply chain information. The dataset contains approximately **80,519 records** related to orders, customers, products, sales, shipping, delivery, geography, discounts, and profit.

### 2. Data Cleaning & Preprocessing

The dataset was examined and prepared using **Power Query**.

The following activities were performed:

- Identifying required fields
- Checking data types
- Cleaning the dataset
- Transforming relevant columns
- Preparing data for analysis

### 3. Data Analysis

The prepared dataset was analyzed using **Power BI and DAX** to calculate important metrics related to:

- Sales
- Orders
- Customers
- Products
- Delivery
- Discounts
- Costs
- Profitability

### 4. Visualization & Dashboard Development

Interactive Power BI dashboards were developed progressively through **four milestones**.

The final project contains **seven dashboard pages** featuring:

- KPI Cards
- Charts
- Tables
- Maps
- Slicers
- Analytical visuals

### 5. Insights & Interpretation

The final dashboard was used to identify trends and patterns related to:

- Sales performance
- Customer contribution
- Product performance
- Delivery efficiency
- Geographic markets
- Shipping modes
- Discounts
- Costs
- Profitability
